\\section{A small example}

\\begin{definition}
A set is finite if it has finitely many elements.
\\end{definition}

\\begin{theorem}
Every subset of a finite set is finite.
\\end{theorem}

\\begin{proof}
A subset cannot contain more elements than the finite set containing it.
\\end{proof}
